# موقع عالم الموكيت للمفروشات

موقع متجر إلكتروني (واجهة أمامية فقط، بدون خادم/قاعدة بيانات) لعرض وبيع منتجات السجاد والمفروشات، مبني فوق تصميم Stitch الأصلي.

## هيكل المشروع

```
index.html          الرئيسية
about.html           من نحن
products.html        كل المنتجات + فلترة حسب القسم
product.html         تفاصيل منتج (?id=معرّف_المنتج)
services.html        الخدمات
contact.html         تواصل معنا
cart.html            سلة المشتريات
checkout.html        إتمام الطلب
order-success.html   تأكيد الطلب
assets/js/data.js    بيانات المنتجات (عدّل هنا لإضافة/حذف منتجات)
assets/js/cart.js    منطق السلة (localStorage)
assets/js/validation.js  التحقق من صحة بيانات النماذج (تواصل معنا / إتمام الطلب)
assets/js/layout.js  الهيدر والفوتر المشتركين + رقم واتساب
assets/js/tailwind-config.js   ألوان وخطوط الهوية
assets/css/style.css أنماط إضافية
assets/img/          صور محلية (خلفيات/أرضيات)
```

## قبل الرفع على الاستضافة — 3 أشياء لازم تعدّلها

1. **رقم واتساب الحقيقي**: افتح `assets/js/layout.js` وابحث عن:
   ```js
   const WHATSAPP_NUMBER = "966549859200";
   ```
   استبدله برقم واتساب شركتك (بصيغة دولية بدون + أو أصفار، مثال لرقم سعودي: `9665xxxxxxxx`).

2. **رقم الهاتف والإيميل في الفوتر**: في نفس الملف `layout.js` وأيضًا `contact.html`، غيّر:
   - `+966 54 985 9200`
   - `ahmedsawah142000@gmail.com`

3. **المنتجات الحقيقية**: افتح `assets/js/data.js` وعدّل/أضف منتجاتك (الاسم، السعر، الوصف، الصورة، القسم). أي منتج جديد تضيفه للقائمة يظهر تلقائيًا في صفحة المنتجات وصفحة التفاصيل.

## كيف يعمل الطلب حاليًا (بدون بوابة دفع)

بما إن الموقع واجهة أمامية فقط بدون خادم، آلية الشراء المطبّقة هي الأكثر شيوعًا للمتاجر بدون باك اند في السوق السعودي/الخليجي:

1. الزائر يضيف منتجات للسلة (تُحفظ في متصفحه عبر localStorage).
2. في صفحة إتمام الطلب يملأ بياناته (الاسم، الجوال، العنوان).
3. عند الضغط على "تأكيد الطلب"، يُفتح واتساب تلقائيًا برسالة جاهزة فيها كل تفاصيل الطلب والمجموع، ليتواصل فريقكم مع العميل ويُتفق على الدفع (تحويل/دفع عند الاستلام) والتوصيل.

**إذا احتجت لاحقًا بوابة دفع حقيقية (مدى/فيزا مباشرة على الموقع)** فهذا يتطلب خادم خلفي (Node.js أو PHP) لأن مفاتيح الدفع لا يمكن وضعها في كود المتصفح لأسباب أمنية. قولّي وقتها وهنجهزها.

## الرفع على الاستضافة

ارفع محتويات هذا المجلد بالكامل (بما فيها مجلد `assets`) إلى المجلد العام لاستضافتك (غالبًا `public_html` في استضافات cPanel)، والصفحة `index.html` هتفتح تلقائيًا كصفحة رئيسية.

## ملاحظة على الصور

بعض صور المنتجات مستضافة على روابط Google (من التصميم الأصلي) — تشتغل تمام لكن يُفضّل لاحقًا استبدالها بصور منتجاتك الحقيقية المرفوعة على استضافتك لضمان استقرارها على المدى الطويل.
